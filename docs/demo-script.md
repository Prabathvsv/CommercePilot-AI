# Demo Script (5 minutes)

## 0:00–0:30 — Problem
Merchants don't lack data. They lack **continuous intelligent action**. Revenue sits in a database, but nobody turns it into a decision and executes it until it's too late.

## 0:30–1:00 — Introduce CommercePilot
Open the dashboard. One core loop: **OBSERVE → UNDERSTAND → DECIDE → ACT → MEASURE → LEARN**.

## 1:00–2:00 — Dashboard
- Revenue is **down** (red trend) — the anomaly detector caught it
- **Revenue at Risk** — high-value customers going quiet
- **AI Opportunity** cards — churn, reactivation, cross-sell

## 2:00–3:00 — Agent reasoning (the differentiator)
Open **Agent Activity** or ask the Copilot:
> "Why is revenue declining?"

Watch the chain:
```
✓ Intelligence Agent — analyzed revenue trends (revenue −X%)
✓ Customer Agent — identified N churn-risk customers
✓ Revenue Agent — calculated campaign ROI
```
Expand a run to show **tool calls** with durations.

## 3:00–4:00 — Campaign
Ask the Copilot:
> "What should I do today to increase revenue?"

It reasons → best strategy = ₹200 cashback → expected revenue ₹2.1L → ROI 2.55× → confidence 84%.

Open the opportunity → **Generate Campaign** → review the AI-generated plan → **Approve**.

## 4:00–4:30 — Execute & Results
Campaign is approved → **Execute** → simulated commerce API delivers it.
```
✓ Campaign executed
✓ 398 customers reached
✓ 71 conversions
✓ ₹2.13L revenue
✓ Actual ROI 2.60×
✓ Prediction error 1.96%
```

## 4:30–5:00 — Why it's genuinely agentic
The system didn't just *talk* about revenue — it **discovered** the problem, **reasoned** over the best fix, **predicted** the outcome, **executed** after human approval, **measured** reality, and **learned** from the gap. That's OBSERVE→ACT→LEARN, not a chatbot with a dashboard.

## Demo Tips
- The deterministic engine means the demo works with **no API key** (offline).
- Seed data guarantees the interesting patterns (revenue decline, at-risk VIPs, cross-sell gap).
- Emphasize the **approval step** — human-in-the-loop agentic commerce.
